# 小窝插件

Operit 项目的“小窝”插件（`com.chixu.xiaowo`）旧构建归档仓库。
这里不是独立 Android 应用，也不是 Operit 官方仓库。

## 内容

每个版本对应一个 Release（标签 `v<版本号>`），附件为 `.toolpkg` 安装包。
在 Operit 中导入 `.toolpkg` 即可安装。

首次归档只收录版本身份明确的旧正式构建。最近的正式版本、预览版、诊断版、测试版和同版本存疑构建暂未收录。
